# NoteNest
Student Notes Sharing Platform
1. Introduction
Hello everyone.
My project title is NoteNest. It is a Student Notes Sharing Platform developed as a frontend web development project.
2. Objective
The main objective of NoteNest is to provide students with a convenient platform to access and share study notes.
3. Technologies Used
I have used three frontend technologies:
- HTML – to create the structure of the website.
- CSS – to design and style the website.
- JavaScript – to add interactive functionality.
